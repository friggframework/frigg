# Get support

Stuck on a deploy, unsure which module to reach for, or wondering whether Frigg already covers your use case? Start here — the community and maintainers hang out in a few places, and paid help is available when you need it.

## Community channels

| Channel | Best for | Link |
| --- | --- | --- |
| GitHub Discussions | Questions, ideas, and longer threads that stay searchable | [friggframework/frigg Discussions](https://github.com/friggframework/frigg/discussions) |
| Community Slack | Quick help, war stories, and early looks at new tooling | [Join via friggframework.org](https://friggframework.org/#join) |

### GitHub Discussions

Open a discussion when you want an answer that others can find later — setup questions, design tradeoffs, or “has anyone done X?” Prefer [Issues](https://github.com/friggframework/frigg/issues) for clear bugs and feature requests with reproduction steps.

### Community Slack

Invite yourself to the Frigg Slack Connect channel from the community form on [friggframework.org](https://friggframework.org/#join) (check **Invite me to the Frigg Slack Connect channel** and submit). Slack is great for fast back-and-forth; Discussions are better for lasting reference.

## Paid help

Frigg is free and MIT-licensed. The team that builds it also offers commercial support, maintenance, and hands-on integration work through [Left Hook](https://lefthook.com). Reach out there when you want SLAs, premium connectors, or help standing up an integration program.

## Looking for a feature that isn’t there yet?

Missing something? Request it, or point a coding agent at the relevant spec with our PR instructions; the team reviews for release.
